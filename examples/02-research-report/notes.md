# 案例说明：文本模式研究报告

## 场景

Markdown 会话导出的研究整理任务。没有精确工具统计、耗时、Token 与成本，
也没有独立的检查记录，用于演示文本模式降级与未验证事项的呈现。
输入为本目录下的 input.md（人工构造、完全脱敏）。

## 预期页面要点

- 页面明示「文本模式」徽标；耗时、Token、成本区块整体不渲染、不估算。
- 首条主张（完成资料框架整理）显示「工具证据（未复验）」：其后有检索工具记录，
  但没有检查记录，因此绝不显示「已复验」。
- 末条主张（完成调研）显示「未验证」：其后无工具记录也无检查记录。
- 「未经实测」的说明保留在原文中，页面不做任何语义改写或补充。
- 交付物卡片：research-notes.md（来源为文本中的文件名）。

## 构建方式

python scripts/casebook.py all input.md --out <输出目录>
